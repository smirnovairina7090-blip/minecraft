МИССИЯ 02JAVA

Как Minecraft узнаёт о новом предмете

Сам файл с кодом ещё не делает предмет частью игры. Его нужно зарегистрировать под уникальным ID.

public static final Item STORM_CORE = register( new StormCoreItem(new Item.Properties().stacksTo(1)), "storm_core" ); ResourceLocation itemId = ResourceLocation.fromNamespaceAndPath( StormLabMod.MOD_ID, id ); // Получаем адрес: storm_lab:storm_core

МИССИЯ 06АЛГОРИТМ

Что происходит после ПКМ

Не нужно разбирать каждую Java-команду. Сначала увидь алгоритм целиком.

01
Игрок использует предмет
Запускается метод use(...).
02
Вычисляется точка впереди
Используется RANGE из ModSettings.
03
Создаются частицы луча
Тип частиц тоже берётся из настроек.
04
В мире появляется молния
Создаётся LightningBolt.
05
Ищутся существа рядом
Радиус задаёт SHOCKWAVE_RADIUS.
06
Существа получают толчок
Сила берётся из KNOCKBACK_POWER.
07
Включается перезарядка
COOLDOWN_TICKS не даёт спамить способностью.
Если нужно полностью заменить механику по ПКМ, какой файл откроем?

МИССИЯ 02REGISTRY

Как Minecraft узнаёт о предмете

// создаём предмет public static final Item STORM_CORE = register( new StormCoreItem(new Item.Properties().stacksTo(1)), "storm_core" ); // даём Minecraft уникальный адрес ResourceLocation itemId = ResourceLocation.fromNamespaceAndPath( StormLabMod.MOD_ID, id ); Registry.register(BuiltInRegistries.ITEM, itemId, item);

Итоговый адрес предмета: storm_lab:storm_core. Первая часть - ID мода, вторая - ID предмета.

Внутреннее имяstorm_coreИспользуют код, модель, рецепт.

МИССИЯ 033D + RESOURCES

Почему отдельная модель сейчас не нужна

У предмета уже есть JSON-модель. Minecraft умеет собирать 3D-форму из кубоидов, поэтому для первого мода Blockbench можно вообще не открывать. Это полезно: ученик сначала понимает структуру мода, а уже потом занимается моделингом.

Базовый путь
models/item/storm_core.json textures → minecraft:block/amethyst_block textures → minecraft:block/copper_block
Работает сразу, дополнительных файлов не требует.
Вау-апгрейд позже
Blockbench ↓ Export Java Block/Item Model storm_core.json + свои PNG
Это отдельная дополнительная миссия.

МИССИЯ 06JAVA

Анатомия ПКМ

Главное здесь не запомнить весь синтаксис. Нужно научиться читать механику как последовательность событий.

1. use()Игрок нажал ПКМ.
2. targetВыбираем точку впереди игрока.
3. sendParticles()Рисуем путь электрического луча.
4. LightningBoltСоздаём настоящую сущность молнии.
5. getEntitiesOfClass()Ищем существ рядом.
6. push()Отбрасываем их от эпицентра.
7. playSound()Добавляем звук.
8. addCooldown()Запрещаем спамить силой.
Если убрать cooldown, что изменится?

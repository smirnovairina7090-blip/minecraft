# Storm Lab - первый WOW-мод для Minecraft 1.21.1

Готовый учебный шаблон на Fabric + Java 21.

Игрок создаёт **Ядро Бури**. По ПКМ предмет выпускает электрический луч, вызывает молнию, создаёт облако искр и ударной волной отбрасывает существ вокруг точки попадания.

## Что ребёнок поймёт за один урок

- где Minecraft узнаёт о новом предмете;
- где лежит Java-логика способности;
- где менять название предмета;
- где менять рецепт;
- где лежит 3D-модель;
- как параметры в коде меняют поведение игры;
- как GitHub Actions превращает исходники в готовый `.jar`.

## Карта проекта

| Хочу изменить | Куда идти |
|---|---|
| Силу, дальность, частицы | `ModSettings.java` |
| Что происходит по ПКМ | `StormCoreItem.java` |
| Добавить/зарегистрировать предмет | `ModItems.java` |
| Название в игре | `assets/storm_lab/lang/ru_ru.json` |
| 3D-модель | `assets/storm_lab/models/item/storm_core.json` |
| Свои PNG-текстуры | `assets/storm_lab/textures/item/` |
| Рецепт | `data/storm_lab/recipe/storm_core.json` |
| Информацию о моде | `fabric.mod.json` |

## Самое безопасное место для экспериментов

Открой:

`src/main/java/ru/creitivika/stormlab/ModSettings.java`

Попробуй менять по одному параметру:

- `RANGE = 12` - дальность;
- `COOLDOWN_TICKS = 60` - перезарядка, 20 тиков = 1 секунда;
- `SHOCKWAVE_RADIUS = 5.0` - радиус волны;
- `KNOCKBACK_POWER = 1.7` - сила отбрасывания;
- `BEAM_PARTICLE = ParticleTypes.ELECTRIC_SPARK` - вид луча.

Для частиц можно попробовать `FLAME`, `SNOWFLAKE`, `PORTAL`, `END_ROD`.

## Как собрать JAR прямо на GitHub

1. Измени файл.
2. Нажми **Commit changes**.
3. Открой вкладку **Actions**.
4. Выбери **Build Storm Lab Mod**.
5. Открой успешный запуск.
6. Внизу скачай artifact `storm-lab-minecraft-1.21.1`.
7. Внутри будет готовый `.jar`.
8. Положи `.jar` в папку `mods` клиента Minecraft 1.21.1 с Fabric API.

## Следующий уровень

Когда базовая версия заработала, ребёнок может сделать собственный вариант:

- Огненное ядро - частицы `FLAME`;
- Ледяное ядро - `SNOWFLAKE`;
- Эндер-ядро - `PORTAL`;
- изменить рецепт;
- переименовать артефакт;
- экспортировать свою модель из Blockbench и заменить `storm_core.json`;
- добавить собственные PNG в `assets/storm_lab/textures/item/` и указать их в модели.

Главная идея урока: **ресурсы отвечают за внешний вид, JSON - за данные, Java - за поведение, регистрация связывает объект с Minecraft, GitHub Actions собирает мод**.

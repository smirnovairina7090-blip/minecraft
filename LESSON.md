# Урок: Minecraft Mod Lab - повелитель бури

Примерная длительность: 45-60 минут.

## 0. Вау-вход

Преподаватель заранее запускает готовый мод, берёт Ядро Бури и по ПКМ показывает луч, молнию и разлетающихся мобов.

Вопрос ученику: **Minecraft сам знает, как работает этот предмет, или мы можем найти каждую его часть в проекте?**

## 1. Расследование проекта

Дайте ученику 5 минут найти четыре вещи:

1. где написано название `Ядро Бури`;
2. где лежит модель;
3. где задан рецепт;
4. где написано, что произойдёт по ПКМ.

После этого соберите схему:

`регистрация -> ресурсы -> поведение -> сборка -> Minecraft`

## 2. Миссия «Хакни бурю»

Откройте `ModSettings.java`.

Сначала поменяйте только:

`RANGE = 12` -> `RANGE = 20`

Сделайте commit и соберите мод через Actions. Ученик должен предсказать результат до запуска.

## 3. Миссия «Новая стихия»

Поменяйте:

`ParticleTypes.ELECTRIC_SPARK`

на один из вариантов:

`ParticleTypes.FLAME`
`ParticleTypes.SNOWFLAKE`
`ParticleTypes.PORTAL`

Теперь способность уже визуально принадлежит другой стихии.

## 4. Миссия «Балансировщик»

Ученик сам выбирает три параметра:

- дальность;
- радиус волны;
- силу отбрасывания.

Перед сборкой он объясняет, почему его артефакт не слишком слабый и не слишком сильный.

## 5. Миссия «Мой мод»

Ученик меняет название и рецепт. Если есть Blockbench, экспортирует собственную item-модель и заменяет `storm_core.json`.

## Финал

Ученик должен без подсказки ответить:

- куда идти, если хочу изменить картинку или модель;
- куда идти, если хочу изменить рецепт;
- куда идти, если хочу изменить механику;
- зачем предмет нужно регистрировать;
- что делает GitHub Actions.

Если он может ответить на эти пять вопросов и самостоятельно поменять хотя бы один параметр, цель урока достигнута.
